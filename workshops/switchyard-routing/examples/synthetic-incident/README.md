# Synthetic incident fallback

Open [demo.ipynb](demo.ipynb) for the original audience notebook, [advanced.ipynb](advanced.ipynb) for implementation details, or [preview.html](preview.html) for the recorded presentation.

Notebooks start in offline rehearsal with paid calls and tracing disabled. Rehearsal uses scripted answers; it does not measure quality, latency or savings. Shared source data, configuration and tools are under the workshop's `data/`, `configs/` and `shared/` folders.

The untouched original notebooks and their hash manifest are preserved locally in `local-research/backups/synthetic-2026-10-15/`, outside Git. Published copies have outputs cleared and safe defaults.
